# 好友召回助手

支持 MuMu / 雷电模拟器、QQ / 微信区的《火影忍者》Windows 辅助工具。

作者：@MinDna

**公益软件 · 允许转载 · 严禁收费**

## 下载

在本仓库的 [Releases](https://github.com/lihua2233/naruto-recall-assistant/releases/latest) 下载 `好友召回助手_v0.4.0.zip`，完整解压后运行 `好友召回助手.exe`。请保留旁边的 `_internal` 文件夹，不要只复制 exe。

## 功能

- 自动换区登录：扫描拥有角色区服，支持从头开始或扫描后选择起始区服，处理领奖和活动弹窗后退出并继续。
- 自动创建新区账号：按起始区号和数量处理，已有角色自动跳过。
- QQ / 微信独立选择；MuMu / 雷电独立连接设置。
- 暂停、继续、停止，区服记录与异常截图。

## 使用

1. 打开模拟器，在游戏中手动登录账号，停在“开始游戏”页。
2. 启动助手，选对模拟器和“游戏账号”（QQ / 微信）。
3. 点击“检测连接 / 识别画面”，确认画面正确。
4. 选择功能和起始方式后开始。具体步骤见压缩包内的简明使用说明。

注：使用自动创建新区账号前，当前账号需已经有一个区达到 40–50 级。

同一模拟器类型只运行一个实例。任务运行时不要同时手动操作该游戏。更新前请关闭旧版。

## v0.4.0 更新

- 减少无效的教学手指识别和重复等待。

- 选区或“开始游戏”未生效时重新识别后重试，各最多 3 次；失败则暂停，不跳区、不误计完成。
